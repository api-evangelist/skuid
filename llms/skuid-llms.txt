# Skuid (Nintex Apps)

> Skuid is a low-code application-development platform for building custom, data-connected user experiences on top of Salesforce and other enterprise systems. Builders assemble Pages from configurable UI components bound to Models, which read and write data through Data Sources (Salesforce, REST, OData, SQL, Google, OpenAI, and more). Skuid exposes a client-side JavaScript API (skuid.model, skuid.$, snippets, component APIs) rather than a hosted REST API, and ships developer tooling — a deployment CLI and a Salesforce DX plugin. Skuid was acquired by Nintex and is now delivered as Nintex Apps.
